# Technical Design Phase

Your goal is to generate `.kiro/specs/<name>/design.md`.
Please read the full instructions for the TECHNICAL DESIGN PHASE in the `kiro-core` skill located at `.agents/skills/kiro-core/SKILL.md`.

**Steps**:
1. Read `requirements.md`.
2. Inspect relevant repository code, architecture, and tests.
3. Write `design.md` explaining HOW every requirement will be implemented. Ensure all mandatory sections are included (Proposed Architecture, Files Affected, Component Design, Data Model, API Contracts, etc).
