# Requirements Phase

Your goal is to generate `.kiro/specs/<name>/requirements.md`.
Please read the full instructions for the REQUIREMENTS PHASE in the `kiro-core` skill located at `.agents/skills/kiro-core/SKILL.md`.

**Steps**:
1. Inspect the repository. Read relevant files.
2. Determine how the requested behavior fits the existing system.
3. Write `requirements.md` ensuring it has all the mandatory sections (Overview, Goals, Non-Goals, Functional Requirements, Acceptance Criteria, Edge Cases, Constraints, Open Questions).
